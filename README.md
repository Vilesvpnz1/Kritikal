# Kritikal

A Blooket cheat menu with a terminal-style UI with **190+ cheats** across every major game mode, search, themes, and live alerts

Based on [Blooket Cheats Plus](https://github.com/randomstuff69/blooketpluscheats/) — rebranded and updated by **Vilesvpnz**.

---

## Features

- **190 cheats** for Global, Host, and all supported Blooket game modes
- **Terminal UI** — drag, resize, minimize, close
- **Search** — filter sidebar modules and cheats
- **Color themes** — Kritikal, Default, Cyber, Matrix, Ocean, Sunset, Violet, Gold, Mint (+ more in Settings → Defaults)
- **Alerts** — live log + leaderboard
- **Chat panel** — in-game chat with commands (`/help`, `/cb`, `/dump`, etc.)
- Full feature list: see [`kritikal-features.txt`](kritikal-features.txt)

## How to use

1. Go to this GitHub repo.
2. Pick **one** of the two ways below.
3. Open [Blooket](https://www.blooket.com) and join or host a game.

### Method A — Bookmarklet (click to run)

open **`kritika-bookmarklet.txt`**, copy the entire line (starts with `javascript:`), create a new bookmark, and paste that line as the URL.

### Method B — Console paste

1. Open **`kritika.js`** from this repo.
2. Select all and copy the entire file.
3. On Blooket, press **F12** → **Console**.
4. Paste and press **Enter**.

Both methods use the **same  script**. Use whichever is easier for you.

### Default keybinds

| Action | Default |
|--------|---------|
| Hide menu | `Ctrl+E` |
| Close / unload | `Ctrl+X` |

Change these in **Settings** inside the menu.
