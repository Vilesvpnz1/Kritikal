KRITIKAL FEATURE GUIDE

Overview
- Kritikal is a browser-injected control panel with a themed UI, category sidebar, quick actions, mini-games, effect overlays, feature search, and AI helper tooling.
- The script supports both direct console execution and bookmarklet loading.

Core UI Features
- Draggable/resizable panel UI.
- Top control buttons:
  - Fullscreen/restore toggle.
  - Feature Search launcher.
  - Minimize/collapse toggle.
  - Close/shutdown button.
- Ctrl+E hide/show keybind.
- Sidebar search to filter module tabs quickly.
- Terminal-style visual theme and animations.

Feature Search Hub
- Dedicated popup opened from the top "Feature Search" button.
- Searches through available feature names across categories.
- Custom-styled scrollbar.
- Hides with Ctrl+E when main panel hides.

AI Assistant (Dedicated Tab)
- Separate AI Assistant section in the sidebar.
- Stores provider-specific API keys.
- Optional model override field.
- Prompt box and response panel.
- Proxy URL support for CSP-restricted environments.
- Includes a system instruction context focused on Kritikal UI/feature assistance.

Settings System
- Import theme settings via JSON.
- Export theme settings via clipboard.
- Preset/default theme switching.
- Keybind configuration:
  - Hide keybind.
  - Shutdown keybind.
- Persistent settings via localStorage.

Compatibility Notes
- Some external URLs and API calls can be blocked by site CSP.
- AI assistant can use a proxy endpoint where direct provider calls are blocked.
- Background URL supports hosts that comply with the current page CSP.
